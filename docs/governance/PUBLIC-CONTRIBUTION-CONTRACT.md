# Public contribution contract

## Code rights

- Contributors retain their copyright.
- Contributions are submitted under `AGPL-3.0-only`.
- Every commit must include a DCO 1.1 `Signed-off-by` line.
- Signoff certifies the right to submit; it does not transfer copyright.

Create a signed-off commit with:

```text
git commit --signoff -m "type: concise description"
```

## Temporarily prohibited contributions

Until a dedicated rights and provenance policy is accepted, do not submit:

- assets, photos, video, audio or scans;
- faces, bodies, voices or other identities;
- club, uniform, sponsor or other branding;
- datasets or annotations;
- trained models, checkpoints or model weights;
- personal data or material with unclear redistribution rights.

Code that can later consume such material may be proposed without bundling the material.

## Independence

Public build, tests, documentation and contribution must not require confidential planning material. Do not reference private paths, private repository contents, prompts, credentials or internal discussions.
