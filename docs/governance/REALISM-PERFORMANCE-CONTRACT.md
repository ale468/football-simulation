# Realism–Performance contribution contract

## Authority order

1. Authoritative-state correctness.
2. Reproducibility and explainability.
3. Observable physical coherence.
4. Measured latency and throughput.
5. Biomechanical plausibility.
6. Visual fidelity.

A lower item must not falsify a higher item. Presentation and ML never decide authoritative contact, possession, ball trajectory, rule or competitive result.

## Required evidence

A change affecting realism or performance states:

- observed phenomenon and baseline;
- expected benefit and causal mechanism;
- invariants that cannot regress;
- CPU, memory and latency impact;
- scenario, build and hardware;
- repetitions, distribution and limitations;
- rollback or fallback.

No fixed runtime budget exists before the first reproducible kernel baseline. Shared CI proves correctness, not absolute performance on reference hardware.
