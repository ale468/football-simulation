# Public roadmap

The roadmap is dependency-driven rather than date-driven. A future phase describes direction; it does not authorize implementation.

| Phase | Status | Public objective |
|---|---|---|
| Phase 0 — Foundation | `COMPLETED` | Independent public repository, license, contribution rules, governance and validation |
| Phase 1 — Deterministic Contact Lab | `ACTIVE` | Headless deterministic kernel with two simplified body proxies and one ball |
| Phase 2 — Parametric Player | `PLANNED` | Canonical body, physical parameters and generated collision representation |
| Phase 3 — Motion and Contact | `PLANNED` | Responsive motion, balance and physical-contact expression |
| Phase 4 — Small-sided Match | `PLANNED` | Multiple agents, selective contact and minimal positional behavior |
| Phase 5 — 11v11 Simulation MVP | `PLANNED` | Bounded offline 22-player simulation |
| Phase 6 — Neural Appearance | `PLANNED` | Subordinate neural deformation, materials and rendering experiments |
| Phase 7 — Roster Scaling | `PLANNED` | Shared human model plus parameters, embeddings, adapters and residuals |

## Promotion rule

A phase advances only after:

- exit criteria and required gates pass;
- evidence is reproducible;
- risks and limitations are current;
- public capability language matches demonstrated reality;
- the maintainer records explicit promotion.
