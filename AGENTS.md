# Public agent contract

- Read `docs/PROJECT-OVERVIEW.md`, `docs/PUBLIC-ROADMAP.md`, `docs/DEVELOPER-JOURNEY.md` and the related Issue before changing files.
- Work only on a `READY` Issue and within the active phase.
- Preserve the authoritative kernel boundary. Presentation, animation and ML do not decide competitive truth.
- Treat realism and performance as evidence-backed decision axes.
- Declare the gate profile, tests, evidence, limitations and rollback.
- Never invent a test, benchmark, capability or evidence result.
- Do not introduce future-phase runtime, ML, rendering, assets or datasets.
- Never include confidential planning material, credentials, private paths or unlicensed third-party material.
- Copilot and other agents do not approve their own work or promote a capability.
- Run the repository validator and applicable tests before reporting completion.
