# Football Simulation

Public source-code repository for an open-source football simulation.

## Status

The project is completing its public foundation. No game, physics engine, renderer, machine-learning model or gameplay implementation has been published yet.

This repository is the authoritative publication surface for source code intended for public use and contribution. Internal planning material is not distributed here and is not required to build, test, study or modify any code that is published here.

The first planned executable is a headless deterministic Contact Lab with two simplified body proxies and one spherical ball. It will establish replay, state hashing, collision evidence and a performance baseline before graphics, animation or ML.
